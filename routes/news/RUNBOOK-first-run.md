> 2026-10-08 首次端到端实跑 t002（尊界V800 刹车踏板断裂）的记录。
> **前提**：跑之前静态检查全绿（自检 78/78、版式 234 文件 0 违规、仓库验证通过）。
> **结论**：所有缺口都是"静态检查查不出、只有真跑才现形"的类型。

## 一、已修（5 个真缺口）

### ① 配图把 2022 年空难新闻配上了今天的新闻 🔴 最严重

**现象**：镜 2 的配图命中「东航 MU5735 班机第二部黑匣子寻获现场 Second Black box...jpg」。

**根因**：`image_query()` 旧优先级是「显式 `image` > **kicker** > 没有」，而 kicker 是
**栏目名**（"现场数据"/"时间线"/"目前"），不是画面描述。拿栏目名检索 Wikimedia Commons
（`gsrsort=relevance`，中英语料错配）返回了毫不相干但词面凑巧命中的图。

**为什么三道闸全没拦住**：

| 闸 | 判定 | 为什么没拦住 |
|---|---|---|
| 授权闸 | CC BY 3.0 ✅ 合规 | 授权与内容真不真无关 |
| 尺寸闸 | 961×720 ✅ 合规 | 同上 |
| 词面闸 | 「现场」二字命中 ✅ 放行 | **`CJK_SHINGLE=2`，任意 1 个二字块就算证据** |

**修**：
- `image_query()` 只认作者显式写的 `image`，**不再回落到 kicker**（kicker 是排版元素）
- 词面闸收紧：中文证据改为「**≥3 字连续公共子串** 或 **≥2 个二字块**」
- 新增 `_longest_common_cjk_run()` —— 滑窗块会错位（"湖南常德"切成 湖南/南常/常德，
  而标题"常德市区"只含 1 块），数块会把真命中误杀

**有意的代价**：2 字地名（"常德"）不再放行。配图请写足 3 字以上。
**"无图比错图好"** —— 宁可少一张图，不要播出视觉假事实。

### ② 渲染工作目录落在系统 temp，被自动清理

**现象**：渲染 15 分钟后 hyperframes 报 `No index.html file found`；工作目录里只剩最后一段音频。

**根因**：`work = tempfile.mkdtemp(prefix="pathb_")` 放在 `%TEMP%`。
渲染要 15 分钟（首次 `npx -y hyperframes` 拉包 + Google Fonts 拉字体占掉大半），
等包拉好时 Windows 临时目录已被系统清理 —— `index.html` 连同前 4 段 mp3/vtt 全没了。

**修**：新增 `DEFAULT_WORK_ROOT = .harness-news-runtime/work/`（与新闻域其他产物同域、
受 gitignore 保护、不被系统清理）。`--work-dir` 仍可显式覆盖。
**顺带发现**：`--work-dir` 参数本来就有，但**自检里零覆盖**。

### ③ 门禁失败不报真话

**现象**：
```
❌ hyperframes check --strict 未通过, 已拒绝渲染
   check 输出尾部: 报告无法解析: .../check.json
   详细 stderr: .../check.err.txt        ← 只给路径
```
而 `check.err.txt` **当时是空的**，真实原因（`No index.html file found`）没人看到。

**修**：`gate_hyperframes_check` 把 stderr 原文并进异常消息；stderr 为空时打工作目录
+ `index.html` 是否存在。**"报不出原因的拒绝等于没有拒绝"** ——
「假绿比红危险」的同一原则在红这一侧也成立。

### ④ 静默丢内容（写稿时踩的）

**现象**：镜 2 的 `title:"断在第几次"`、镜 5 的 `title:"目前"` —— **既不上屏也不出声**。

**根因**：`title` **不进配音**，而 `news-coral` 的 `stat` / `closer` / `quote`
**没有标题位**（七版式里这三个没有）。两头都不接，稿子就没了。`path_b_build` 只打一条 ⚠，
且是**渲染 15 分钟之后**。

**修**：新增 `routes/news/scripts/check_scene_contract.py`，把检查挪到写稿那一刻。
报四类问题：标题无落点 / 条目超行 / `onscreenAccent` 缺 `｜` 标记 / `body` 为空。
`--demo` 自带 3 反例 + 1 干净稿（防"把闸修死"）。

**为什么没把 ⚠ 改成停机**：会破坏既有工作流（t001 那批稿都是这么过的）。
**治本在"写稿时查"，不在"渲染时拦"。**

### ⑤ fact-check 技能是空壳

31 行只有三个能力名词 + 一句「产物：事实核查报告」。**它是硬门禁，挡着每一条片子**，
却没有判据、没有输出格式、没有"不通过怎么办"。补成完整判据 + 五节核查单格式。

## 三、方法论收获

1. **静态检查全绿 ≠ 能用**。这次 5 个缺口，静态检查一个都查不出来 ——
   因为它们全在"两个真实系统交互"的地方（渲染器↔系统 temp、版式↔契约、
   检索词↔语料、闸门↔错误信息）。**只有真跑会现形。**

2. **测试会固化缺陷**。`t_relevance_gate_refuses_legally_clean_but_wrong_picture`
   原来明确断言「二字共享即命中」是正确行为 —— 缺陷被测试固化了。
   收紧时它变红，说明**改口径必须同步改测试的意图注释**，否则后人不知道为什么红。

3. **"假绿比红危险"在红侧同样成立**。门禁拒了渲染（对的），但只说"无法解析"（错的）——
   **报不出原因的拒绝等于没有拒绝**。

4. **数值型判据要可校准**。`CJK_SHINGLE`、`L2_REVIEW_LOW`、共享 token 阈值…—
   这次又被 `SHARED_TOKENS` 手抄坑了一次（校准函数第一次跑就抓到 `#f0f0f0` 只有 3 次）。
   **凡是用数值当判据的地方，都要有复算入口。**
