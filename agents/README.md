# agents/ — 组织图

**这个目录只回答一个问题：由谁来跑。** 「怎么做」在 `.agents/skills/`（跨工具收敛，一份四家吃），
「谁来做」在这里（各家格式互不相认，所以这里全是**编译产物**的母版，design §8.1）。
两个目录分开，是因为两种东西的**可共享性**不同——不是为了好看。

## 三层

```
CEO     用户               拍板、给资源、担责。全图唯一能被「等用户确认」阻塞的节点
 └─ leader                 编排者。主线程角色，不派发给自己做实现
     ├─ explorer           摸底。只读
     ├─ backend            服务端实现。只拥有服务端路径
     ├─ frontend           前端实现。只拥有前端路径
     ├─ qa                 测试。只拥有测试路径，禁改被测代码
     ├─ reviewer           挑刺。只读，物理禁写
     ├─ novelist           正文。只拥有正文目录，写完必跑机检
     ├─ reporter           成稿。只拥有稿件目录，可上网取料
     └─ fact-checker       核对。可上网，禁写稿件
```

## 每位差在哪条权限（判据：design §8.1「agent 存在的唯一理由是权限隔离」）

| 成员 | 路线 | 独有能力 | 由什么执法 |
|---|---|---|---|
| `leader` | 全（仅 L 档） | 有 `Agent`、**无 `Write`/`Edit`** | 平台工具集 |
| `explorer` | 全 | 只读集，**禁写** | 平台工具集 |
| `backend` | code | 只写服务端路径 | **路径所有权**（下表） |
| `frontend` | code | 只写前端路径 | 路径所有权 |
| `qa` | code | 只写测试路径 + 必跑测试 | 路径所有权 + 证据令 |
| `reviewer` | 全 | 只读挑刺，**禁写** | 平台工具集 |
| `novelist` | novel | 只写正文目录 + 写完必跑三个机检脚本 | 路径所有权 + PostToolUse 机检 |
| `reporter` | news | 只写稿件目录 + 可上网 | 路径所有权 |
| `fact-checker` | news | 可上网、**禁写稿件**（核对者不改稿） | 平台工具集 |

**路径所有权是本项目自己加的机制**，因为平台的 agent 工具集表达不了「只准写 `src/main/**`」：
`compiler/hooks/pre-tool-use.ts` 读 WU 声明的路径清单，命中范围外的 `Write`/`Edit`/`apply_patch`
即 exit 2 拦截（Claude / Codex / CodeBuddy 同一套输出契约，design §10）。
所以「后端 / 前端 / 测试」不是三个换皮的提示词——**它们各自的写权限真的不重叠**，
并行派发时物理上撞不了同一个文件。

## 加一个名字之前必须先回答

1. 它和已有成员差**哪条权限**？差不出 → 不配做 agent，写成 skill 或做成同一 agent 的不同 skill 组。
2. 它的领域知识在哪份 skill？agent 文件必须 ≤15 行（design §11），**因为正文都在 skills/**。
   v1 的教训：七份角色 838 行，`coder.md` 与 `implementer.md` 是同一件事的两份定义。
3. 哪条路线用它？写进 `engine/routes/<line>.md` 的引用清单，一页纸只渲染本路线的名单。
