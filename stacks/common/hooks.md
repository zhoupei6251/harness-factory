# 通用 Hooks 规则

本文件是建议，不代表宿主已配置或启用 hooks。先检查项目与宿主的实际配置，遵守已有门禁和执行限制，不自动安装或修改用户级 hooks。

- 工具执行前只做必要的快速边界检查；不要在每次读写前运行全项目编译、测试或扫描。
- 一组相关编辑完成后，合并运行项目已有的格式检查、类型检查与受影响测试，优先文件或模块范围。
- 全量构建、测试与依赖审计按项目要求或实际风险执行一次；检查通过后仅因新修改、失败或未解决问题重跑。
- 自动格式化和修复只处理授权范围，避免改动无关文件；耗时任务设置合理超时，失败信息应说明原因与后续动作。
- 各 hook 单一职责，避免相互触发或重复执行相同检查。配置语法与退出码以实际宿主为准。

项目禁止的命令不能通过 hook 绕过。无法执行时记录未验证项和建议命令，不假称检查通过。
