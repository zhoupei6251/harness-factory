# 安全边界检查

读取 upstream/SKILL.md 中与本次改动有关的章节：输入、权限、注入、会话、日志或依赖。沿真实调用链定位信任边界并给出具体证据。

示例是参考，不是项目规范：沿用现有校验库、认证方式和数据库驱动；不得因示例引入 Zod、Supabase 等新依赖。参数化 SQL 仍须匹配当前驱动。上传检查还需验证内容和保存路径，不能仅信任扩展名/MIME。Cookie、CSRF、限流按应用架构选择，不机械套用多种相互重叠方案。

仅检查本次涉及的风险。上游 npm update、audit fix、云资源和部署示例不构成执行授权；修改生产配置或无关依赖前仍遵守用户范围。
