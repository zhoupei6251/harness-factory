# 短视频文案工作流（入口 = 路由器）

这是一个 **skillset 入口**，不是"把五个技能依次跑一遍"的流水线。
每个阶段只做一件事；脚本生成阶段 **必须且只能选一个** 生成器。

## 为什么不能串联多个生成器

三个生成器解的是同一道题（写一条短视频脚本），但输出的结构、节奏和格式互不兼容。
串联跑 = 为同一份需求付 2–3 次生成成本，最后还要人工裁决哪版算数。
除非用户明确要 A/B 两版，否则只选一个；**多选一个不比选错一个便宜**。

## 步骤 0（可选）：竞品文案提取

用户给了竞品分享链接时，用 **douyin-copy-extract** 提取标题/口播文案，产出原版与精简版素材。
用户只给了主题或产品信息时跳过本步。

## 步骤 1（必做）：选一个脚本生成器

| 用户需求 | 用哪个 | 为什么 |
|---|---|---|
| 品牌 IP / 专家口吻、作战地图、产品文档、PDF/Word 输入、批量生成 | **short-video-script-creator** | 唯一参数化 + 口吻对标 + 文件解析的生成器；按其 SOP 先提交参数清单、等确认 |
| 快速一条口播稿、以"黄金 3 秒"钩子为核心 | **viral-script-writer** | 单文件方法论，最快出稿；适合热点快发 |
| 多平台/多类型（知识、测评、直播话术、分镜）、需要平台风格与模板 | **cn-video-script-writer** | 带 references/ 平台风格与脚本模板，覆盖面最广 |

选定后按该技能的 SKILL.md 执行，不要把另外两个的规则混进来。
信息不足时问清最小必要项，**不要**以"换个生成器再试一次"代替澄清。

## 步骤 2（可选）：爆款标题与封面文案

用户要标题/封面/话题标签时，用 **viral-title-generator** 批量出标题。
脚本生成器自带的标题建议与它二选一，不要同时交付两套互相矛盾的标题。

## 输出

- 主产物：**一个**脚本（Markdown），格式跟随所选生成器
- 可选产物：标题集、封面文案、话题标签
- 不要用"多版脚本大礼包"掩盖选择成本；用户要 A/B 时再显式跑第二个生成器

## 新闻域衔接

`route=news` 的步骤 2 从本入口进入，产物落在
`.harness-news-runtime/articles/<topic_id>-script.md`，回填 MEMORY `drafts[]`。
脚本里加 `屏: <整句>` 单独行（`onscreen:`）让 path_b_build 的 `check_onscreen` 闸门放行。
