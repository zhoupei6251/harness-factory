# Novel Generator — 爽文小说自动生成器

> 根据用户提供的方向/关键词，自动生成创作提示词并产出小说章节。
> 适用场景：快速启动、批量创作、维护连续性。

## 激活条件

- 用户提供小说方向/题材/关键词
- 需要快速生成章节
- 需要维护多角色/多地点/多情节的连续性
- 爽文类创作（都市/修仙/玄幻/重生/系统流）

## 支持的题材

| 题材 | 关键词 |
|------|--------|
| 都市逆袭 | 总裁/重生/首富/兵王/神医 |
| 修仙玄幻 | 筑基/金丹/元婴/宗门/飞升 |
| 穿越重生 | 穿越/重生/系统/金手指 |
| 系统流 | 叮/系统/任务/积分/兑换 |
| 甜宠言情 | 霸道总裁/甜文/虐渣 |
| 悬疑推理 | 破案/侦探/连环杀手 |

## 自动生成流程

### Step 1: 方向解析

解析用户提供的内容方向：

```
输入：「写一个都市重生逆袭的小说」
  ↓
题材：都市重生
关键词：逆袭/重生/复仇/商战
基调：爽文/热血
目标读者：男性向
```

### Step 2: 提示词生成

自动生成结构化提示词：

```markdown
## 创作提示词

### 世界观设定
{自动生成的世界观描述}

### 主角设定
- 姓名：
- 身份：
- 核心能力：
- 性格特征：
- 金手指来源：

### 配角设定
- 反派：
- 盟友：
- 暧昧对象：

### 情节框架
- 开局：{重生点}
- 前期：{原始积累}
- 中期：{崛起}
- 后期：{巅峰对决}

### 爽点设计
1. {爽点1}
2. {爽点2}
3. {爽点3}
```

### Step 3: 章节生成

根据提示词生成章节：

- 自动维护角色状态
- 自动维护情节连续性
- 自动埋设伏笔和悬念
- 自动生成章节钩子

## 连续性维护

### 角色状态表

```markdown
## 角色状态

### 主角
| 属性 | 值 |
|------|---|
| 姓名 | 张三 |
| 身份 | 公司职员 → 总裁 |
| 财富 | 0 → 1亿 |
| 武力 | 普通 → 暗劲 |
| 好感度-女主 | 30 → 60 |

### 配角
| 姓名 | 角色 | 当前状态 |
|------|------|---------|
| 李四 | 兄弟 | 追随 |
| 王五 | 反派 | 被击败 |
```

### 情节进度表

```markdown
## 情节进度

| 章节 | 事件 | 状态 |
|------|------|------|
| 1-3 | 重生+复仇计划 | ✅ 完成 |
| 4-6 | 挖第一桶金 | ✅ 完成 |
| 7-9 | 遭遇女主 | 🔄 进行中 |
| 10-12 | 商业布局 | 📋 待写 |
```

## 使用示例

### 示例1：快速启动

```
用户：我要写一个修仙小说，主角资质平庸但心性坚定
  ↓
Generator 产出：
- 完整的主角设定
- 宗门/修炼体系设定
- 前10章的大纲
- 第一章初稿
```

### 示例2：批量生成

```
用户：继续写到第20章
  ↓
Generator 产出：
- 第11-20章正文
- 更新角色状态表
- 更新情节进度表
```

## 禁止

- ❌ 生成含有违法违规内容的小说
- ❌ 生成有明显抄袭痕迹的内容
- ❌ 跳过 novel-guidelines 直接生成
- ❌ 不维护连续性导致前后矛盾
