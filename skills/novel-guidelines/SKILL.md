# Novel Guidelines — 小说写作前思维基线

Novel 域强制性前置检查。任何小说创作任务启动前必须加载。
基于 63 条 AI 写作陷阱。

## 核心原则

简洁 > 堆砌 → 精准 > 套路 → 人物声音 > AI 味

## AI 痕迹（写前必知）

| 陷阱 | 规避 |
|------|------|
| 眼中闪过一丝光芒 | 改成具体肢体语言 |
| 嘴角勾起一抹微笑 | 改成自然表情 |
| 深吸一口气 | 改成动作或心理 |
| 首先/其次/最后 | 用自然过渡 |
| 仿佛/似乎 | 直接陈述 |
| 不是A不是B而是C | 直接说"是C" |
| 万能结尾 | 用具体悬念钩子 |

## 人设原则

每个角色说话风格独特，行为符合性格，查人物设定再动笔。

## 伏笔原则

埋：清晰具体。收：意料之外情理之中。忌：机械降神。
