# Novel Simplify — 章节自查简洁度

写后审稿前必须自查。对应 Code 域 simplify。

## 自查清单

### AI 痕迹
- [ ] 眼中闪过/嘴角勾起/深吸一口气
- [ ] 首先/其次/最后
- [ ] 仿佛/似乎
- [ ] 不是A不是B而是C
- [ ] 车轱辘话

### 冗余
- [ ] 每句话承载新信息
- [ ] 无重复表达

### 人物声音
- [ ] 风格独特
- [ ] 符合角色身份

### 节奏
- [ ] 有冲突或转折
- [ ] 结尾有悬念钩子
