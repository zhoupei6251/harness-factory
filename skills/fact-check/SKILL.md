# 事实核查（硬门禁）

> **判据：`drafts[].fact_check` 必须是 `passed` 才允许进渲染。**
> `flagged` → 回步骤 2 改稿。不通过不许"先渲了再说"。

## 1. 为什么它挡得住"看起来合理的错"

AI 写稿会把**看似合理的数字当真**：76.6 万写成 76.8 万、把"部分车型"说成"全系"、
把测试方的判断当既成事实、把"记者获悉"写成"官方宣布"。
这类错播出去是**平台虚假信息风险**，比排版事故严重一个量级。

AIGC 标识解决不了这个问题：角标只声明"这是 AI 生成的"，不保证"这是真的"。

## 2. 核心能力

- **多源交叉验证**（≥3 个**独立**来源，见 §3）
- **逐项核对**：稿件里每个数字/时间/主体/引语各占一行
- **存疑项处置**：单源数据怎么处理，写清楚
- **观点 vs 事实分离**：媒体与曝光方的**判断**不是事实
- **时效性风险**：事件尚未定性时，结论怎么留退路

## 3. 多源交叉：什么算"独立"

| 判据 | 说明 |
|---|---|
| 独立 | **不能三篇都转述同一篇原稿**。看署名与细节差异：不同源给出**不同细节**才叫独立 |
| 一致 | 核心事实（时间/主体/行为/结果）要逐字对得上，不是"意思差不多" |
| 不足 | 只有 1 个来源 → 标 ⚠️ 单源，按 §5 处置 |

**反面教材（2026-09-29 实测）**：「湖南常德」在 Commons 全文检索里第一条合规结果是
**西藏步甲虫论文插图**（CC BY 4.0、尺寸也够）—— 授权闸放行、尺寸闸放行、词面闸也放行。
新闻侧的同类风险：三家媒体都转述财联社 = 看着交叉了，实际单一信源。

## 4. 必核清单（这些最容易出错）

| 类别 | 必核项 | 典型错法 |
|---|---|---|
| 数字 | 金额/百分比/价格区间/次数/里程/时长 | 凭印象写、"约"与精确值混用 |
| 时间 | 发布日 vs 事发日 vs 上市日 | 「9月30日公告」≠「10月8日出事」 |
| 主体 | 品牌名 / 公司名 / 官方便称 | 「尊界」是品牌，「江淮汽车」是上市公司，别混 |
| 引语 | 官方回应 | 加工成更硬的语气；转述不标来源 |
| 归因 | 「记者获悉」≠「官方宣布」 | 抹掉不确定性 |
| 引申 | 结论/预测 | 「将导致」当已发生 |

## 5. 存疑项处置（不许含糊过去）

| 情形 | 处置 |
|---|---|
| 单源但具体可核 | **保留**，稿件不强调为「权威结论」 |
| 单源且是分析性数据 | **剔除**，或改为「据××测算」并点名 |
| 与国标/常识冲突 | **剔除**，并查是否有更新数据 |
| 事件尚无官方结论 | **必须留退路**：成片显式说「尚未发布」，标题**不得下判断结论** |
| 稿件标题已下判断 | **改标题** —— 事件未定就不许定性 |
| 涉事方与曝光方有竞争关系 | 只陈述事件与各方回应，**不传播动机判断** |

**观点不是事实，不许进稿件**：「非偶发故障」「远超日常工况」「质量堪忧」——
这些是**分析判断**，只有曝光方或媒体的主观结论。
替代表达：closer 镜用「官方结论｜尚未发布」+ 各方回应原话表达同一件事，不站队。

## 6. 产物：核查单（必写，不许口头过）

落 `routes/news/evidence/<date>-<topic_id>-fact-check.md`，五节：

1. **多源交叉表** —— 来源 / 性质 / 一致点，**并判断独立性**
2. **逐项核对表** —— 稿件每个数字一行：表述 / 核查结果 / 来源编号 / 判定（✅ / ⚠️单源 / ❌）
3. **存疑项与处置** —— 每条写清"为什么存疑 + 怎么处理"（**这一节最有价值**）
4. **时效性风险** —— 何时可能反转、发布后失真怎么办
5. **结论** —— `passed` / `flagged` + 一句话说清放行理由

**样例**：`2026-10-08-t002-fact-check.md`（4 源交叉 / 3 项单源 / 2 项观点排除 / 1 项剔除）

## 7. 检索工具

- **WebSearch** 多关键词多轮 + **WebFetch** 读原文细节（拿具体数字与引语）
- ⚠️ **RSS 源不能当事实来源**：`news-collect` 采的 feedx 镜像新鲜度差异极大
  （实测 thepaper 的"最新"条目在 297 天前），只能当线索
- ⚠️ **百度搜索结果页不能当出处**：采集器给的 url 是 `m.baidu.com/s?word=...`，
  那是搜索页不是原文，要按标题定位到真实媒体原文
