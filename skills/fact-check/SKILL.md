# 事实核查

## 激活条件

- 需要验证新闻内容的真实性
- 需要交叉验证多个信息来源
- 需要标注不确定或存疑的内容

## 核心能力

### 验证能力
- 多源交叉验证
- 数据来源可靠性评估
- 时间线一致性检查

## 产物

- 事实核查报告
