# Auto Compact - 智能上下文压缩

## 何时使用

### 应该压缩

| 时机 | 原因 | 操作 |
|-----|------|-----|
| **研究/探索完成** | 大量探索上下文已无用 | 立即 /compact |
| **里程碑达成** | 阶段成果需固化 | /compact 后保存状态 |
| **方法失败** | 证伪的方案应清除 | /compact 后换方法 |
| **上下文超过 60%** | 预留处理空间 | 主动压缩 |
| **任务切换** | 隔离不同任务 | /clear 或 /compact |

### 不应该压缩

| 时机 | 原因 | 替代操作 |
|-----|------|---------|
| **实现中途** | 会丢失变量名、文件路径 | 等到断点 |
| **调试追踪中** | 调用栈上下文关键 | 等定位完成 |
| **重构进行中** | 多处关联状态 | 等重构完成 |
| **有未保存变更** | 状态还在内存 | 先 Write/Edit |
| **复杂计算中途** | 中间结果在上下文 | 等计算完成 |

## 压缩决策流程

```
上下文使用率检测
    ↓
< 40% ───→ 不压缩（正常范围）
    ↓
40-60%
    ↓
检查是否有安全压缩点
    ↓
有 ───→ 建议 /compact
    ↓
无
    ↓
> 60%
    ↓
强制建议压缩（可能影响质量）
```

## 压缩内容选择

### 保留优先级（从高到低）

| 优先级 | 内容 | 理由 |
|-------|------|-----|
| P0 | 未提交的文件变更 | 工作进度 |
| P0 | 当前任务目标 | 防止迷失 |
| P1 | 刚读取的文件内容 | 可能需要引用 |
| P1 | 有效的实现思路 | 避免重复尝试 |
| P2 | 探索过程记录 | 后续可能需要 |
| P2 | 已尝试的方法 | 避免重复 |
| P3 | 闲聊内容 | 无关紧要 |
| P3 | 证伪的方案 | 已证明无用 |

### 压缩后的典型结构

压缩后保留最近的 10-20 条消息，通常包含：
- 最近读取的文件
- 当前任务描述
- 有效的中间结果
- 下一步计划

## 压缩执行

### 自动触发条件

当满足以下任一条件时，建议压缩：

1. **上下文使用率 > 50%** 且有安全压缩点
2. **连续 3 次** 提到"上下文"相关
3. **用户询问**上下文相关问题
4. **任务完成**里程碑后

### 手动触发

```bash
/compact          # 标准压缩
/compact verbose  # 显示压缩详情
/clear           # 完全重置（慎用）
```

### 压缩后的状态确认

压缩后应该：
1. 确认当前任务目标清晰
2. 确认关键文件路径已知
3. 确认未保存的变更已 Write
4. 确认下一步行动明确

## 状态固化协议

### 何时固化

- 大任务中途（每 2-3 小时）
- 里程碑达成时
- 会话结束前
- 压缩前

### 固化内容

```markdown
# 会话状态 - {timestamp}

## 任务
{当前任务描述}

## 进度
- [x] {已完成}
- [ ] {进行中}
- [ ] {待处理}

## 关键文件
- {文件路径}: {当前状态}

## 重要发现
{如有}

## 下一步
{具体行动}
```

### 固化位置

| 类型 | 位置 |
|-----|------|
| 项目级状态 | `.claude/sessions/{date}-{topic}.md` |
| 全局记忆 | `~/.claude/memory/sessions/` |
| 进度跟踪 | `docs/progress/{task}.md` |

## 最佳实践

1. **预防优于压缩** - 定期固化状态，减少压缩需求
2. **安全第一** - 不确定时不压缩，等待自然断点
3. **保留证据** - 压缩前确认关键信息已固化
4. **验证恢复** - 压缩后确认能继续工作
5. **成本意识** - 高上下文使用率时主动压缩

## 常见问题

### Q: 压缩后丢失了重要信息怎么办？

A: 检查是否已固化到文件。如果未固化，下次注意在关键节点保存状态。

### Q: 什么时候用 /clear 而不是 /compact？

A: /clear 用于完全切换任务或开始新阶段。/compact 用于继续同一任务但清理冗余。

### Q: 压缩会影响工作质量吗？

A: 正确执行时不会影响。确保保留：任务目标、文件路径、未提交的代码。
