# Novel Writer CN — 中文小说创作框架

> 创建小说创作的整体框架：人物设定、人物关系、剧情发展、多版本结局。
> 与 novel-36-beats（结构化节拍）互补：本 skill 负责"人物+关系+剧情"，36-beats 负责"节奏+章节"。

## 激活条件

- 用户要求"写小说"、"创建故事框架"
- 新项目开书，需要建立人物设定和剧情框架
- 需要多版本结局设计
- 需要人物关系图

## 使用示例

### 用户请求：「写一个修仙逆袭的故事框架」

```
Planner 执行：
1. 使用 novel-writer-cn 创建人物设定
2. 设计主角（资质平平但心性坚韧的少年）
3. 设计配角（师父/师姐/对手）
4. 规划主线剧情（从废物到天才）
5. 规划支线（感情线/宗门争斗）
6. 设计 2-3 个结局版本
7. 交由 novel-36-beats 规划章节节奏
```

## 禁止

- ❌ 只做人物设定，不规划剧情
- ❌ 人物设定与实际写作脱节
- ❌ 结局设计过于相似（要有明显差异）
- ❌ 跳过人物声音特征设计
