# 抖音口播脚本优化工作流 · 完整方法论

> 配套 `dify-prompts.md` 含可直接抄进 Dify 的 Node A / Node B Prompt。本文为策略与规则手册。

## 1. 抖音 2026.7 分发机制认知（优化依据）

- **分发模型：实时赛马 + 多路召回**。新视频先小流量赛马，按实时指标决定加推；同时走搜索、关注、同城等多路召回。旧"离散流量池"模型已过时。
- **指标权重排序**（决定优化重心）：
  1. 完播率（最高权重，决定冷启动能否放量）
  2. 评论 / 转发 / 收藏（深度互动，评论权重高于点赞）
  3. 点赞
  4. 关注 / 转粉
  5. 负反馈（单独降权，触发即限流）
- **铁粉机制（核心）**：老粉互动权重高；内容要兼顾"拉新钩子"与"铁粉专属感"。
- **搜索流量 / 抖音 SEO（增长极）**：口播与标题埋可被搜索的词（长尾问句转口语陈述），提升搜索召回。
- **账号信用分 / 权重**：违规、低质、同质化会降权；稳定更新、合规是前提。
- **推流窗口**：发布后前几小时是赛马关键期，开头 3 秒留存决定冷启动。

## 2. 合规红线（2026.7 完整版）

### 2.1 ⭐ AI 生成内容强制标识（直接命中本技术栈，必做）
- 声音克隆属**深度合成**，依《人工智能生成合成内容标识办法》（2025.9.1 施行）须**显式 + 隐式**双标识：
  - **显式**：片尾/画面上标注"AI 配音生成""AI 生成内容"等。
  - **隐式**：音频/文件元数据嵌入生成标识（平台要求时）。
- 不加标识 = 违规风险，可能限流或下架。

### 2.2 常规红线
- 极限词（"最""第一""绝对"）、虚假悬念、造谣、引战、侵权（音乐/肖像/素材版权）。
- 主页/简介/评论区导流外部（视规则收紧程度）。

## 3. ⭐ 防同质化变异层（批量混剪出片必做）

- 抖音对**同质化内容**（尤其模板化批量混剪）打压降权——**单账号批量出片同样中招**，不只是矩阵号。
- 做法：
  - Hook 类型轮换（不每片套同一句开头）。
  - 句式变异 + 注入具体数字/场景（去模板腔）。
  - 去重指纹：素材组合随机只在"同语义池"内、加差异化转场/滤镜。
  - 每片输出"与同质化内容的差异点"（anti_homogenization_note）。

## 4. 0 阶段 · 主题延展（初版口播文案入口）

初版口播文案（`raw_script`）是 Node A 的输入，两种来源：
- **① 手写**：用户写/粘贴草稿，Node A 直接优化。
- **② 主题延展（批量推荐）**：用户给 `topic` + `key_points`（3–5 条，必填）+ 可选 `materials` + `account_persona`，AI 先延展成初稿再优化。

**0 阶段输入**：`topic` / `key_points` / `materials*` / `account_persona` / `content_type` / `video_duration`
**0 阶段输出**：`raw_script`（口语化、结构清晰初稿）+ `draft_note`（本片讲清什么、主打哪条要点）
**0 阶段质量门（必做，否则禁止进优化）**：
- [ ] 覆盖全部 `key_points`？
- [ ] 有具体画面感/案例，非空泛口号？
- [ ] 字数匹配 `video_duration`（中文 TTS ≈ 4–5 字/秒）？
- [ ] 口吻贴合 `account_persona`？
- 任一条不通过 → 带 `feedback` 重跑（≤2 次），仍不过标记"初稿待你手写补全"。

**落地形式**：独立 Dify LLM 节点，或合并进 Node A 前置分支（`raw_script` 空而 `topic`+`key_points` 有值时先延展再优化）。质量门须先于 Node A 执行。

## 5. 双节点架构（Dify）

```
开始节点(变量) → Node A 口播优化(LLM) → 变量提取器A → Node B 标题优化(LLM) → 变量提取器B → 输出节点
                                                          ↓(可选) 数据回灌
```

- **变量提取器（每 LLM 节点后必加）**：把 JSON 拆成独立变量。`optimized_script`→下游百炼 TTS；`title_options/tags`→人工发布选优（不做 API 自动发布）。
- **条件分支 + 反馈重跑（真闭环）**：Node A `score`(1–10) ≥7 放行；<7 把"上版文案+得分+扣分项"组装成 `feedback` 回灌 Node A 做针对性修订（只改弱项）。最多 2 次，仍 <7 打"质量预警"不阻塞。
- **Dify DAG 约束**：画布不支持原生回边。① Loop 节点包裹 Node A（最大迭代 2、score≥7 break）；② 外部编排层重试（推荐，更可控）。
- **时长对齐与声画同步（硬性门槛）**：`video_duration` 是计划时长。混剪实际时长由下游剪映素材决定。**必须以 TTS 实际音频时长为唯一基准**对齐下游剪映 beat 切点；估算字数仅用于初版输出，不得直接用于模板时间轴。偏差 >±1s 必须返工。
- **数据回灌（可选）**：开放平台数据 API 需企业资质，通常不可用；改人工定时拉创作者后台数据（完播/评论率）回写触发重优化。

## 7. TTS 朗读适配规则（纯文本保守版，不依赖 SSML）

1. **断句靠标点**：逗号短顿、句号长顿；单朗读句 ≤20 字一顿。
2. **规避多音字/生僻字误读**："重"要、"行"业等换词或加语境；不用生僻字。
3. **中英混排加空格**："AI 配音""SEO 优化"前后留空格。
4. **数字统一读法**："2024年"→"二零二四年"，"25分钟"→"二十五分钟"。
5. **字数≈时长**：中文 TTS 约 4–5 字/秒，`video_duration` 秒上限约 `video_duration*4.5` 字，超则精简；适当语气词增自然度。

## 8. 标题优化维度（Node B）

1. 点击率：前 18 字放钩子/利益/情绪/悬念/数字。
2. 搜索 SEO：融入行业词、痛点词、长尾问句。
3. 话题标签：3–5 个精准 # 标签。
4. 展示位适配：标题与口播首句可呼应勿完全重复；禁标题党、禁极限词。
5. A/B 备选：固定出 5 个，风格差异化（悬念/利益/数字/共鸣/争议各一）；5 个作发布候选池，单视频仅挂 1 个。

## 9. shot_plan 与声画匹配硬约束（由下游剪映混剪执行）

`shot_plan` 的声画匹配硬约束——每槽 ≤5s、visual_prompt 必须具体（如"办公桌上咖啡杯特写、热气袅袅"）、`source` 不得留空；剪映轨道切点严格对应 beat 时间边界、无跨 beat 素材；TTS 音频实际时长为唯一基准倒推精确时间戳（偏差 >±0.5s 不合格）；以及出片前校验清单（每 ≤5s 一槽？切点 = beat 边界？音频实际 vs 预估偏差 <±1s？逐拍听声画是否对齐？任一条不过禁止导出 mp4）——**均由下游 `video-render-engine` 技能的「剪映混剪」章节执行**，详见该技能文档。中游只负责在 Node A 产出符合该硬约束结构的 `shot_plan` 供下游消费。

## 10. 成本与算力（9.5 省钱核心思路）

> 默认 SaaS 形态你本地零 GPU 压力；付费集中在生图/下游 TTS/剪映。省钱 = "贵且可复用的节点前置缓存、摊薄单次成本"。

- **AI 生图**：按主题预生成素材池+缓存复用（引 9.4）。
- **声音克隆音色**：训一次复用，之后每条只付合成费。
- **LLM 结果**：同主题/同 `content_type` 缓存，相似选题复用或微调。
- **轻节点本地/开源，重节点 SaaS 靠缓存摊薄**：文案/选片/剪辑走 Dify 自托管、FFmpeg/Remotion；生图/下游 TTS 用 SaaS，靠缓存摊薄。长期想省 API 费才自建（引入显卡成本，默认不推荐）。
- 单条 30s/60s 视频成本约 ¥0.2–2（跑量+缓存压到 ¥0.1–0.5/条）；一次性投入：下游音色训练 ¥100–500 + 下游剪映订阅 ¥30–100/月。

## 11. Hook 类型库（含反模板规则）

- 类型：反常识 / 强冲突 / 悬念 / 利益前置 / 身份代入。
- 反模板：同一账号不同片轮换类型；注入真实具体细节；禁止全片套同一句。
- 铁粉呼应：老粉专属感话术（"老粉都知道…"）。

## 12. 时长策略差异化

- 短（≤30s）：单爆点+强钩子，断句极简。
- 中（30–60s）：Hook→知识点→情绪→金句→互动，每 5–10s 一爆点。
- 长（>60s）：多知识点分段，每段独立钩子+落点。

## 13. 落地建议（三条关键）

1. **先跑通单条再批量**：用一条真实主题验证全链路（延展→优化→TTS→混剪→导出），再谈规模化。
2. **Prompt 沉淀为模板**：Node A / Node B 存成 Dify 提示词模板，换 `content_type` 与素材库即通用。务必保留**防同质化变异层**、**AI 标识**、**TTS 朗读适配**三段不可省略。
3. **链路末端（2026.7.17 校正）**：无企业资质 → 不做抖音开放平台自动上传/定时发布；末端为下游剪映导出 mp4 本地交付，mp4 由人工上传抖音（发布、排期、标题 5 选 1 在人工环节）。
