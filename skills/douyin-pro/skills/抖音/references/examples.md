# 完整示例：输入 → 输出（Golden Reference）

本文档提供两种入口模式的**完整端到端示例**，包含精确的变量值、模型实际输出 JSON、以及逐字段注释。用于：
- 首次加载 skill 后的冒烟测试（smoke test）
- 向他人演示工作流行为
- 调试时对比"预期 vs 实际"的基准线

## 使用这些示例的正确方式

1. **冒烟测试**：首次导入 DSL 后，用示例 A 的变量值跑一次，对比输出是否与上述 JSON 结构一致（不需要逐字相同，但字段结构和质量标准必须一致）。
2. **调试基线**：当输出异常时（如 score <7 或 shot_plan 为空），拿当前输出与本文档的标准输出做 diff，定位是哪个维度出了问题。
3. **演示素材**：向团队或客户展示工作流能力时，可直接截取本文档的 JSON 作为"输入→输出"的效果展示。

## 示例 C：错误输入 → 友好报错（E001-E003 类）

以下展示**错误输入**以及系统应返回的**友好报错话术**（不是系统崩溃，而是有明确指引的错误提示）。

### C1: key_points 为空（触发 E001）

| 输入 | 错误响应 |
|------|---------|
| `raw_script`: *(空)* | **⚠️ E001: 缺少必填信息** |
| `topic`: 怎么做短视频 | `key_points` 不能为空。你给了主题"怎么做短视频"但没有给具体要点。 |
| `key_points`: *(空)* | 请至少提供 3 条具体要点，例如： |
| `content_type`: 知识 | > 1. 完播率比点赞重要 10 倍 |
| | > 2. 前 3 秒决定 80% 的人是否划走 |
| | > 3. 同质化内容会被系统直接降权 |
| | → （见本文「示例 A」） |

### C2: key_points 太泛（不触发 E001 但导致 E007 质量预警）

| 输入 | 结果 |
|------|------|
| `key_points`: 1.要做好内容 2.要坚持更新 3.要研究爆款 | Node A 可以运行但 score 可能只有 5–6（因为要点太泛无法产出差异化文案）→ 触发 E007 质量预警 |
| **修正后**: 1.完播率>点赞权重 2.前3秒=生死线 3.同质化=物理淘汰 | score 通常能到 7+ |

**经验法则**：每条 key_point 应该是一个**可以被反驳的具体观点**（含数字/对比/反常识），而不是正确但无信息的口号。

### C3: video_duration 异常值（触发 E002）

| video_duration 值 | 响应 |
|------------------|------|
| `5` | ⚠️ E002：5 秒过短（≈22 字），不足以完成 hook + 一个知识点。建议最小 15 秒。 |
| `300` | ⚠️ E002：300 秒（≈1350 字）超过单轮 LLM 推荐输出上限。建议拆成 3–5 条 60 秒视频的系列。 |
| `-10` 或 `abc` | ⚠️ E002：video_duration 必须是正整数（单位：秒），推荐范围 15–120。 |

### C4: raw_script 和 topic/key_points 同时为空

| 输入 | 响应 |
|------|------|
| `raw_script`: *(空)* | ❌ E001：两种输入源都为空。请二选一： |
| `topic`: *(空)* | > A) 在 `raw_script` 中粘贴你的初稿 |
| `key_points`: *(空)* | > B) 在 `topic` + `key_points`(≥3条) 中提供主题和要点 |
| | → 无法继续运行。 |

## 示例 D：边界时长案例

### D1: 15 秒超短视频（极限压缩）

| 变量 | 值 |
|------|-----|
| `topic` | 一句话让客户买单 |
| `key_points` | 1.痛点前置 2.利益量化 3.行动指令 |
| `content_type` | 种草 |
| `video_duration` | `15` |

**Node A 输出关键特征**：
- `optimized_script` ≈ 60–70 字（极致精炼）
- `shot_plan` 仅 3 槽（0-3s hook / 3-12s 核心卖点 / 12-15s CTA）
- `hook_options` 必须一击即中（没时间铺垫）
- `golden_line` 与 CTA 合并

**注意事项**：15 秒对模型输出精度要求极高——任何废话都会挤掉核心信息。建议用更强的模型（qwen-max / GPT-4o）并降低 temperature 到 0.5。
