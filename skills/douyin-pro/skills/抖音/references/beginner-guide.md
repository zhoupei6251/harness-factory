## 第二步：导入我们的工作流模板

### 2.1 找到模板文件

本 skill 自带一个 `dify-workflow-template.json` 文件。它的位置在：

```
skill 安装目录/assets/dify-workflow-template.json
```

如果你是按标准方式安装的，路径通常是：
- **C 盘**：`C:\Users\32233\.workbuddy\skills\douyin-script-optimizer\assets\dify-workflow-template.json`
- **D 盘备份**：`D:\Workbuddy\.workbuddy\skills\douyin-script-optimizer\assets\dify-workflow-template.json`

> 找不到？直接搜索文件名 `dify-workflow-template.json` 就能找到。

### 2.2 导入到 Dify

1. 在 Dify 左侧菜单点击「工作室」（Studio）
2. 点击「创建应用」→ 选择「工作流」（Workflow）→ 选择「导入 DSL」
3. 在弹出的文件选择框中，选中上面的 `dify-workflow-template.json` 文件
4. 点击「打开」/「确认」

**成功标志**：你会看到画布上出现了 4 个方框，从左到右依次是：

```
开始 → Node A → Node B → 结束
```

如果看到了这 4 个方框 + 它们之间有连线 → **导入成功！✅** 继续下一步。

## 第三步：配置模型（把"占位符"换成你自己的）

### 3.1 为什么需要这一步？

模板里默认填的是一个假模型名（`openai/gpt-4o-mini`），你需要换成你自己有权限使用的真实模型。

### 3.2 怎么操作？

1. 在画布上找到标着 **「Node A」** 的方框 → **双击它**
2. 弹出一个编辑面板
3. 找到「模型」或「Model」那一栏 → 当前显示的是占位模型名
4. 点击下拉箭头 → 选择你有 Key 的模型：
   - **如果你有阿里云通义 Key** → 选 `qwen-plus` 或 `qwen-max`
   - **如果你有 DeepSeek Key** → 选 `deepseek-chat`
   - **如果你有 OpenAI Key** → 选 `gpt-4o`
5. 同样操作 **Node B** 方框 → 双击 → 换成同一个模型（或不同的也行）
6. 点保存/关闭编辑面板

> 💡 **不知道自己有什么 Key？**
> - 如果你用过 ChatGPT → 你有 OpenAI Key
> - 如果你用过通义千问/阿里云百炼 → 你有通义 Key
> - 都没有？去 https://platform.deepseek.com 免费注册一个 DeepSeek Key（目前免费额度很大）

## 第四步：填写你的内容（核心！）

### 4.1 找到「开始」节点

画布最左边那个写着「开始」的方框 → 双击它

你会看到一个输入表单。里面有 **10 个字段**，但别慌——我们只填 **5 个必填的**，其他可以跳过。

### 4.2 填写指南（照抄下面的例子格式）

| 字段名 | 你要填什么 | 示例（直接参考这个格式写） |
|--------|----------|----------------------|
| **raw_script** | 留空！不填！ | *(空的)* |
| **topic** | 你的视频主题 | `为什么你的短视频没人看` |
| **key_points** | 3–5 个具体要点（**最重要！**） | `1.完播率比点赞重要 2.前3秒决定生死 3.算法赛马机制 4.同质化直接降权 5.声画不匹配拉低观感` |
| **content_type** | 四选一 | `知识` （或者 `种草` / `剧情` / `观点`） |
| **target_audience** | 你的目标观众 | `想做短视频但播放量上不去的创作者` |
| **video_duration** | 视频时长（秒） | `45` |
| **account_persona** | 你的人设（可选但不建议跳过） | `一个懂算法的短视频实战老炮` |
| **materials** | 可选，留空即可 | *(空的)* |
| **publish_time** | 留空 | *(空的)* |
| **feedback** | 留空 | *(空的)* |

### 4.3 关键规则：key_points 怎么写才算合格？

❌ **错误写法**（太泛了，模型会输出空洞内容）：
```
1.要做好内容
2.要坚持更新
3.要了解算法
```

✅ **正确写法**（每条都是一个具体的、可以反驳的观点）：
```
1.完播率比点赞重要10倍
2.前3秒决定80%的人是否划走
3.同质化内容会被系统直接降权，这不是惩罚是物理规则
4.声画不匹配会拉低观感和完播率
5.算法一直在赛马，你的内容跟别人一样凭什么赢
```

**简单判断标准**：每条 key_point 读起来应该像是一个**有经验的人在分享他的独家发现**，而不是教科书上的正确废话。

### 4.4 填完后

点击保存/关闭编辑面板。

## 第五步：运行！

### 5.1 点哪里？

在 Dify 画布的 **右上角** 或 **右下角**（取决于界面版本），找到一个 **「运行」** 按钮。

它可能叫：
- 「Run」
- 「▶ 运行」
- 「调试运行」

总之就是那个让你开始执行的按钮。

### 5.2 运行中会发生什么？

点击后你会看到：
1. **Node A 开始处理** → 可能等 **30 秒到 2 分钟**（它在帮你延展初稿+优化文案+生成 shot_plan，这是最耗时的步骤）
2. 然后 **Node B 自动执行** → 大约 **10–30 秒**（它基于优化稿生成标题）
3. 出现「运行完成」提示

> ⏳ **第一次比较慢是正常的**——模型在"思考"。后面再跑同样的类型会快一些。

## 第六步：看结果！

### 6.1 看结束节点的输出

1. 点击画布上的 **结束（End）** 节点
2. 右侧（或下方）会出现它的输出结果
3. 因为模板已预配置 Node A 的 JSON 结构化输出，结束节点直接给出**拆好的字段**，不用你从一大段 JSON 里找

**最重要的 3 个字段**（先只看这些）：

| 字段 | 长什么样 | 表示什么 |
|------|---------|---------|
| `optimized_script` | 一段中文口语化文案 | **这就是你优化后的口播文案！可以直接拿去用** |
| `score` | 一个数字，如 `8` | 质量分数（10 分制）。**≥7 就是合格的** |
| `title_options` | 5 个标题的数组 | 5 个标题候选（下一步看） |

### 6.2 提取你要的东西

**① 优化后的口播文案**：

在结束节点的 `optimized_script` 字段里，那段文字就是你的成品文案。

复制它 → 可以直接粘贴到：
- 交给下游百炼 TTS 生成配音
- 或者先用眼睛读一遍看看满不满意

**② 标题（结束节点的 `title_options` 字段）**：

里面是 5 个标题，比如：

```json
["标题一", "标题二", "标题三", "标题四", "标题五"]
```

从这 5 个里**选一个你最满意的**，作为你视频发布时的标题。

### 6.3 第一次跑通检查清单 ✅

- [ ] Node A 有输出？（不是报错/空白）
- [ ] `optimized_script` 是一段能读得出来的中文？
- [ ] `score` ≥ 7？
- [ ] Node B 有输出？`title_options` 有 5 个标题？

**全部打勾 → 🎉 恭喜！你已经跑通了第一条！**

## 🔧 常见小白问题 Top 5

### ❌ 问题 1：一点运行就报错 "缺少必填信息"

**原因**：`key_points` 为空或不足 3 条。

**解决**：回到第四步，确保 `key_points` 至少填了 3 条具体要点。参考上面 4.3 的示例格式。

---

### ❌ 问题 2：运行后 score 只有 5 或 6，感觉质量不行

**原因**：可能是 key_points 太泛，或者模型不够强。

**快速修复**（按顺序试）：
1. 先改 key_points —— 把笼统的换成具体的（加数字、加对比、加反常识）
2. 还是不行？换更强的模型（如 `qwen-max` 替代 `qwen-plus`）
3. 再不行？把 `video_duration` 从 45 改成 30（短一点的文案更容易写好）

---

### ❌ 问题 3：运行了很久（超过 3 分钟）还没反应

**原因**：模型服务慢或网络问题。

**解决**：
- 等 1 分钟再看看（首次调用有时很慢）
- 超过 5 分钟还在转 → 取消重试一次
- 反复超时 → 检查你的 API Key 是否有效/余额是否充足

---

### ❌ 问题 4：输出的 optimized_script 里有 #标签 或 **加粗** 符号

**原因**：模型偶尔混入了格式标记。

**解决**：手动删掉那些符号就行（`#xxx`、`**文字**`、```代码块```）。后续版本我们会加自动清洗。

---

### ❌ 问题 5：我不知道该选哪个模型 / 我没有 API Key

**解决方案（按难度排序）**：

| 方案 | 难度 | 成本 | 操作步骤 |
|------|------|------|---------|
| **DeepSeek（推荐新手）** | ⭐ 最简单 | 免费/极便宜 | 访问 https://platform.deepseek.com → 注册 → 创建 API Key → 复制 Key 到 Dify |
| **通义千问** | ⭐⭐ 简单 | 低费用 | 访问 https://dashscope.aliyun.com →（下游配音）开通阿里云百炼/通义服务 → 创建 API Key |
| **OpenAI GPT-4o** | ⭐⭐ 中等 | 较贵 | 访问 https://platform.openai.com → 创建 API Key（需境外支付） |

> 💡 **强烈推荐小白先用 DeepSeek**——注册简单、免费额度大、中文效果好、价格极低。
