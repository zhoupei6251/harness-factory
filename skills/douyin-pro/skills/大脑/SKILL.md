## Overview / When to Use

### 三层架构简述

```
大脑层（本技能）── 定方向 / 定选题 / 定红线 ──▶ 中游 脚本优化器 ──▶ 下游 渲染引擎 ──▶ 成片
```

| 层级 | 角色 | 核心任务 | 边界 |
|------|------|---------|------|
| **上游 大脑层** | 战略 + 合规闸门 | 定方向 / 定选题 / 定红线 | **不写口播稿、不画分镜、不配音** |
| 中游 production | 脚本优化器 | 策略 → 优化脚本 / 标题 / 分镜 | 不做策略决策 |
| 下游 render | 渲染引擎 | 出片 | 只执行，不判合规 |

### When to Use
- 新账号冷启动，需要系统化的定位与选题策略
- 老账号流量停滞，需要诊断并重新定位
- 批量 AI 生产视频前，需要过合规闸门
- 多赛道切换，需要差异化策略剧本
- 需要将策略以结构化字段传给中游/下游管线

### 最小化问卷（3 题，快速启动）

只问赛道、产品、变现方式三题，其余字段用安全默认值：
- 内容类型：知识（通用）
- 目标人群：25-35 岁都市白领（通用）
- 预算：1000-5000（起步级）
- AI 数字人：否（安全默认）
- 发布时间：即时
- 合规风险：中（走 B 级路线）

> 最小化问卷适合"先出方向再细化"的场景，产出的 JSON 可在后续迭代中覆盖。

## 2. 账号定位与人群锚定

> **核心结论**：粉丝数量 ≠ 流量特权。平台已把"粉丝质量"纳入账号信用评级，5000 精准垂类粉丝的商业价值 > 10 万泛粉。

### 定位决策表

| 维度 | 泛粉定位（淘汰） | 精准定位（推荐） |
|------|----------------|----------------|
| 内容锚点 | 蹭热点、什么火跟什么 | 解决一类明确人群的固定痛点 |
| 人群描述 | "所有人" | 带职业/场景/矛盾的细分画像 |
| 人设语言 | 通用、无记忆点 | 有观点、可被收藏复访 |
| 质量目标 | 点赞量 | 收藏率 + 复访率 |

### 账号信用评级三因子

1. **精准度**（标签契合度）——平台给账号打的标签与实际内容是否一致
2. **铁粉占比**（高复访核心用户）——反复回访的真爱粉比例
3. **复访率**（内容被反复回看的频次）——单条内容的回看指数

### 产出 `account_positioning` 模板

```json
{
  "category": "美妆",
  "product": "平价国货护肤品",
  "fan_count": 3200,
  "persona": "成分党+实测派，用数据说话，拒绝玄学",
  "content_pillar": "拆解成分 + 真实使用对比 + 避坑",
  "credit_target": "B+",
  "quality_goal": "收藏率 > 12%，复访率 > 8%"
}
```

## 3. 选题价值设计与话题库

> **核心结论**：算法已从"24 小时短期赛马"转向"**7 天长效价值考核**"。数据权重：**收藏 > 复访 > 完播 > 点赞 > 评论**。

### 选题价值四象限

| 象限 | 特征 | 平台态度 | 策略建议 |
|------|------|---------|---------|
| **高收藏·高复访** | 教程/清单/避坑 | 推流友好 | ★ 主力选题，投入 70% 精力 |
| 高完播·低收藏 | 爽感/猎奇 | 仅过基础池 | 控制比例，不超过 20% |
| 高点赞·低复访 | 情绪共鸣 | 权重下降 | 谨慎使用，不超过 10% |
| 低完播·低互动 | 自嗨内容 | 冷启动即停推 | 砍掉，不投入 |

### 话题库生成 Prompt 模板

```
你是抖音选题策划专家。基于以下信息，生成 10 个"高收藏·高复访"象限的选题：

账号定位：{persona}
目标人群：{target_audience}
产品/服务：{product}
内容类型：{genre}

每个选题要求：
1. 有明确的目标用户痛点
2. 可拆分为 3-5 个子话题（形成系列）
3. 标注收藏动机（用户为什么想收藏？）
4. 标注复访钩子（看完这条，为什么还看下一条？）
```

## 4. 爆款脚本模型与冷启动约束

### 五段式标准模型

```
钩子（0-2s）→ 痛点放大（2-5s）→ 方案给出（5-30s）→ 证据呈现（30-40s）→ 行动引导（40-45s）
```

### L1 冷启动池三大生死线

| 指标 | 阈值 | 脚本对应动作 |
|------|------|-------------|
| 2 秒留存 | ≥ 70% | 第 1 句抛悬念/利益/反差，**禁**"大家好我是…" |
| 3 秒留存 | ≥ 55% | 前 3 秒出现核心冲突或结果预告 |
| 5 秒完播 | ≥ 40% | 前 5 秒完成"问题→代价"建立 |

> 任一指标不达标 → 系统停推。脚本模型必须让开头 3 秒**全部服务于留存**，不允许任何"铺垫式"开场。

### 钩子类型菜单（6 选 1）

| 类型 | 示例 | 适用赛道 |
|------|------|---------|
| 数据冲击 | "90% 的人涂防晒都白涂了" | 知识/美妆 |
| 反常识 | "越贵的洗面奶越毁脸" | 美妆/观点 |
| 利益前置 | "今天这个成分，能让你少花 3000 块" | 带货/种草 |
| 恐惧放大 | "不改掉这个习惯，账号永远做不起来" | 知识/剧情 |
| 身份认同 | "如果你也是敏感肌，这条一定要看完" | 美妆/观点 |
| 悬念设置 | "我用这个方法，3 天涨了 5000 粉" | 全赛道 |

## 5. 流量池战略与破局策略

### 6 级流量池前三级量化生死线

| 层级 | 曝光区间 | 核心考核 | 生死线 | 备注 |
|------|---------|---------|--------|------|
| **L1 冷启动池** | 100–300 / 0–24h | 2s/3s/5s 留存 | ≥70%/≥55%/≥40% | 任一不达标停推 |
| **L2 基础池** | 1000–5000 | 有效完播率/互动指数 | ≥35%/≥10% | 纯 AI 批量线在此被降权 |
| **L3 待推荐池** | 5000–30000 | 收藏率/复看率/关注转化 | ≥8%/≥5%/≥2% | **80% 创作者卡在这里** |
| L4–L6 | 逐级放大 | 长尾价值 + 铁粉复访 | — | 长尾周期 7–14 天 |

### 破局建议

- **卡 L1**：钩子太弱 → 回到 §4 钩子类型菜单换钩子
- **卡 L2**：内容同质化 → 启动防同质化变异（中游执行）
- **卡 L3**：缺少收藏/复访动机 → 回到 §3 选题四象限，增加"可收藏性"

## 6. 四赛道策略剧本

### 6.1 带货赛道

| 维度 | 策略 |
|------|------|
| **适用特征** | 有实体产品、橱窗或直播变现、重转化轻娱乐 |
| **钩子策略** | 利益前置 + 恐惧放大（"错过这条你会多花冤枉钱"） |
| **五段式侧重** | 方案段（产品展示）和证据段（对比/实测）各占 35% |
| **合规红线优先级** | ③红线闸门（虚假价格/极限词）> ④导流闸门 |
| **render_channel 推荐** | `jianying`（快出混剪）或 `digital_human`（出镜带货口播） |
| **即用 Prompt 片段** | "你是抖音带货博主，卖{产品}。用利益前置钩子，口播风格紧凑、每 3 句点一次痛点。产品功能→价格优势→限时利益三层递进。" |

### 6.2 知识赛道

| 维度 | 策略 |
|------|------|
| **适用特征** | 无实体产品、靠内容涨粉/星图/知识付费变现 |
| **钩子策略** | 数据冲击 + 反常识（"你以为的 XX，其实全错了"） |
| **五段式侧重** | 方案段（干货）占 50%，证据段（案例/数据）占 25% |
| **合规红线优先级** | ③红线闸门（虚假权威/极限词）> ⑥矩阵闸门 |
| **render_channel 推荐** | `jianying` 或 `ffmpeg`（纯静态图+配音，成本最低） |
| **即用 Prompt 片段** | "你是抖音知识博主，讲{主题}。用反常识钩子开头，每 10 秒给一个可操作的具体方法。结尾给收藏理由（'这条你一定会回来翻'）。禁止书面连接词。" |

### 6.3 剧情赛道

| 维度 | 策略 |
|------|------|
| **适用特征** | 强人设、强情绪、短冲突+反转结构 |
| **钩子策略** | 悬念 + 身份认同（"如果你也遇到过这种情况…"） |
| **五段式侧重** | 痛点段（冲突建立）占 40%，保持节奏每隔 5s 一个小翻转 |
| **合规红线优先级** | ②人设闸门（防零修改）> ⑥矩阵闸门（跨账号结构雷同） |
| **render_channel 推荐** | `remotion`（程序化动效）或 `jianying` |
| **即用 Prompt 片段** | "你是一个剧情号，讲{故事场景}。开头 2 秒内建立冲突（谁和谁/因为什么/后果）。每 5 秒一个情绪小起伏。结尾给反转或悬念钩子留到下一集。" |

### 6.4 观点赛道

| 维度 | 策略 |
|------|------|
| **适用特征** | 强立场、强金句、情绪共鸣导向 |
| **钩子策略** | 反常识 + 身份认同（"这个观点可能会得罪人，但我必须说"） |
| **五段式侧重** | 钩子段和证据段各占 30%，金句密度全赛道最高 |
| **合规红线优先级** | ③红线闸门（极限词）> ⑤质量闸门（开头情绪张力） |
| **render_channel 推荐** | `digital_human`（出镜口播）或 `jianying` |
| **即用 Prompt 片段** | "你是一个敢说真话的观点号博主。每 15 秒输出一条可独立传播的金句（≤30字）。立场鲜明、不骑墙。用个人经历做论证，不堆砌数据。" |

## 7. 变现与投流策略

### 变现路径决策

| 路径 | 门槛 | 适用 | 费率/佣金 |
|------|------|------|---------|
| 橱窗带货 | 500 粉 | 低粉起步 | 技术费按评级（B级10%，C级20%，D级40%） |
| 直播带货 | 1000 粉 + 开播时长 | 有口播/控场能力 | A/B级达人佣金6%-10%，C/D级13%-20% |
| 星图广告 | 1w 粉 + 信用评级 B+ | 内容能力强 | 平台抽佣 + 达人分级 |
| 知识付费 | 需企业资质 | 系统课程/IP | 固定费率 |

> **核心策略**：走 A/B 级合规原创路线，靠费率返还 + 稳定转化盈利，而非极限词冲 D 级高佣。

### 投流（DOU+）原则
- DOU+ 是**放大优质内容的杠杆**，不是拯救劣质内容的救命稻草
- 只投"已通过 L2 自然验证 + 已标注 AI + 已人工二改"的内容
- 优先投 L3 卡点内容做破圈，不给冷启动兜底
- 自 2026.6.15 起，"AI 合规专属流量池"额外给**已标注+人工二次修改**内容推流

## 8. AI 生产合规闸门

### 六闸判定表

| 闸门 | 判定标准 | 不通过处置 |
|------|---------|-----------|
| **① 标注闸门** | 发布页勾选 AI 标识 + 前 5 秒可见标识 ≥3 秒 | **拦截**，禁止进入渲染 |
| **② 人设闸门** | 含人工二次修改（口播改写/素材替换/表情微调） | 退回中游二改 |
| **③ 红线闸门** | 四类违规词：稀缺逼单/虚假价格/售后造假/极限词 | **拦截**，标注命中词 |
| **④ 导流闸门** | 无私域信息（含谐音变体"薇♥""加 V""威新"） | **拦截**，强制替换 |
| **⑤ 质量闸门** | 开头钩子满足 L1 生死线 | 退回中游重做钩子 |
| **⑥ 矩阵闸门** | 跨账号结构不雷同 | 标记连坐风险，差异化改编 |

### 六闸串联执行器（伪代码）

```python
def run_compliance_gates(
    ai_label_config: dict,
    modification_log: list[str],
    script_text: str,
    overlay_text: str,
    hook_text: str,
    matrix_scripts: list[str] = None,
) -> dict:
    """六闸串联执行。任一不通过立即拦截并返回命中闸门与原因。"""
    gates = [
        ("标注",   check_label(ai_label_config)),
        ("人设",   check_persona(modification_log)),
        ("红线",   check_redline(script_text)),
        ("导流",   check_no_leak(script_text, overlay_text)),
        ("质量",   check_quality(hook_text)),
    ]
    if matrix_scripts:
        gates.append(("矩阵", check_matrix(matrix_scripts)))

    results = {}
    all_pass = True
    for name, (passed, detail) in gates:
        results[name] = {"passed": passed, "detail": detail}
        if not passed:
            all_pass = False
            break  # 第一道不通过即终止

    return {"all_pass": all_pass, "gates": results}
```

> 以上为签名/伪代码级别，具体规则数据（违规词库、相似度阈值）以平台最新公告为准。

## 10. render_channel 推荐决策树

```
需要真人出镜口播？
├─ 是 → digital_human（数字人）
│       条件：有授权肖像 + 驱动方案就绪
│       组合：digital_human + cosyvoice（情感口播）/ baike（中文克隆）
│
└─ 否 → 内容是否有大量程序化动效需求？
         ├─ 是 → remotion（程序化渲染）
         │       条件：Node.js ≥18 就绪
         │       适用：模板化批量、需要版本管理的系列内容
         │
         └─ 否 → 素材主要是静态图片 + 配音？
                  ├─ 是 → ffmpeg（极简合成）
                  │       条件：ffmpeg 已安装，适合零外网、快速出片
                  │
                  └─ 否 → jianying（默认混剪）
                          条件：本机安装剪映
                          适用：带货快出、新手友好、拖拽式剪辑
```

## 13. FAQ

**Q1: 大脑层和中游的边界到底在哪？**
A: 大脑不写口播稿、不画分镜、不配音。大脑产出的是"方向级"策略字段（定位/选题/合规闸门/render_channel 推荐），中游把这些策略落实为 optimized_script/shot_plan/title_options。

**Q2: 没有粉丝的新号适合用什么策略？**
A: L1 冷启动只投 100-300 精准标签用户，与粉丝量无关。优先走精准定位+高收藏选题（教程/清单/避坑），靠内容质量过关而非粉丝基数。

**Q3: 四个赛道能混用吗？**
A: 建议主赛道选择一个（70% 精力），辅赛道一个（20%），测试赛道一个（10%）。不要 4 赛道均分，容易定位模糊。

**Q4: 合规闸门必须全开吗？**
A: 标注闸门强制全开（法律要求）。人设闸门和矩阵闸门可根据实际场景关闭（如单人单号无需矩阵闸门）。但建议默认全开，按需关闭。

**Q5: render_channel 由大脑定还是中游定？**
A: 大脑给出初始推荐（基于赛道/出镜/模板化等条件），中游根据 shot_plan 的视觉素材类型细化并最终确定。详见 §10 决策树。

**Q6: 最小化问卷产出的策略够用吗？**
A: 够用于"先跑通第一条"的场景。批量生产或正式运营时建议用完整问卷，精准度显著更高。

**Q7: L3 卡住怎么破？**
A: 80% 创作者卡在 L3。检查收藏率与复看率是否达标——如果收藏率低，回归 §3 选题四象限增加"可收藏性"（教程/清单/对比表）；如果复看率低，加强系列化内容的前后钩子。

**Q8: 带货 500 粉门槛不够怎么办？**
A: 先以知识/观点内容涨精准粉到 500，期间沉淀人设和内容风格，达标后再切带货。

**Q9: 私域导流零容忍具体包括什么？**
A: 手机号、微信号、QQ号、二维码，以及谐音变体（"薇♥""加 V""威新""❤"等暗号）。一次违规关橱窗 7 天，两次永久封杀。

**Q10: 大脑层产出的 JSON 怎么传给中游？**
A: 方式一：在对话中直接复制 §9 的 handoff JSON 示例填值后发给中游 agent。方式二：让主理人调度——大脑 agent → 主理人 → 中游 agent。

## 14. 质量承诺与自检清单

### 质量承诺
- 所有策略字段必须基于最新平台规则（2026.7.21 基准）
- handoff JSON 必须与下游 Input Protocol 字段对齐（枚举值合法）
- 合规闸门判定不模糊——每一闸给明确"通过/不通过"结论
- 不写模糊策略"做好内容就行"——每条策略可被中游直接执行

### 自检清单

- [ ] 账号定位含 category / persona / content_pillar / credit_target 四项
- [ ] 选题方向全部落入"高收藏·高复访"或"高完播·低收藏"象限，无低价值选题
- [ ] 脚本模型明确了五段式侧重与开头约束（禁"大家好"类开场）
- [ ] 六合规闸门已全部判定（标注/人设/红线/导流/质量/矩阵）
- [ ] handoff JSON 含全部 11 个字段，render_channel / dubbing_method 为合法枚举值
- [ ] render_channel 推荐与赛道/出镜/模板化条件一致
- [ ] dubbing_method 推荐与网络条件（离线/云端）一致
- [ ] 每日策略速查卡已填充到 Day 0-14
- [ ] FAQ 覆盖了用户账号的实际场景
