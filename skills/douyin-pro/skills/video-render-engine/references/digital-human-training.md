# 数字人训练方法（Path A 参考）

> 本文件是 **Path A（高质量生产）** 的参考资料：讲清楚「怎么训练/克隆一个专属数字人」，
> 与 `SKILL.md §9.5` 的「数字人驱动（推理）」互补——§9.5 是"有了模型怎么出片"，本文件是"模型从哪来"。
> 内容仅供合规用途（已获授权的本人 / 品牌代言人 / 授权 IP），**严禁克隆他人、公众人物、未成年人**。

---

## 1. 三种数字人形态（先选形态再选工具）

| 形态 | 说明 | 典型用途 | 训练/制作成本 |
|------|------|---------|--------------|
| **2D 真人数字人（口播）** | 一张授权肖像 / 一段短视频 → 克隆形象 + 声音，音频驱动口型 | 口播、知识、带货、新闻播报 | 低（SaaS 秒级 / 开源本地训练） |
| **3D 数字人** | 建模 + 骨骼绑定 + 驱动，可任意视角 | 品牌 IP、虚拟偶像、游戏化 | 高（专业团队/数月） |
| **卡通 / 虚拟形象** | 二次元 / Q 版，Live2D / VTube Studio 驱动 | 动漫向、年轻化账号 | 中（立绘 + 绑定） |

> Path A 短视频最常用的是 **2D 真人数字人口播**，下面方法以此为主。

---

## 2. 训练链路三要素（三者齐备才能出片）

一个数字人 = **形象（脸/身）+ 声音 + 驱动**，缺一个都跑不起来：

```
   授权素材（肖像视频 + 人声）
        │
        ├─① 形象克隆──→ 形象模型（2D 数字人形象）
        │
        ├─② 声音克隆──→ 声音模型（见 §8 配音层：百炼 / GPT-SoVITS / CosyVoice / VoxCPM2）
        │
        └─③ 驱动推理──→ 输入文本 → §8 配音 → §9.5 数字人驱动 → 成片
```

- **① 形象克隆** 与 **③ 驱动** 的方法见本文第 4、5 节。
- **② 声音克隆** 的方法已在 `SKILL.md §8` 完整给出（百炼 §8.2 / GPT-SoVITS §8.3 / VoxCPM2 §8.4 / CosyVoice §8.5），本文不再重复，只补充训练数据要求。

---

## 3. 训练数据硬标准（决定模型质量的下限）

### 形象（视频 / 肖像）素材
- **授权**：必须取得肖像权人**书面授权**（含可用于 AI 生成合成的明确许可）。
- **画质**：≥1080p，正脸，单一固定机位，均匀光照，无墨镜/口罩/大幅遮挡。
- **时长**：建议 **1–5 分钟**连续讲话（SaaS 平台往往 10s–1 分钟即可秒级克隆；本地训练模型建议更长更稳）。
- **表情**：自然微表情、轻微头部摆动即可，**避免**剧烈转头、快速走动、强美颜/滤镜导致的"塑料感"。
- **背景**：简洁纯色背景最佳，降低分割难度。

### 声音素材
- **授权**：与形象同人、书面授权。
- **质量**：安静环境录制，**单人声、无背景音乐/杂音**，10–30s 起（百炼等平台可更短）。
- **覆盖**：尽量覆盖常用声调与语速，克隆音色更稳。

### 绝对禁止
- ❌ 未授权他人肖像 / 声音
- ❌ 克隆公众人物 / 明星
- ❌ 涉及未成年人
- ❌ 用于诈骗、仿冒、不实背书

## 4. 本地训练范式（开源，免费但需自配环境）

适合"不想把素材上传第三方、要完全私有化"的账号。

### 4.1 常用开源工具

| 工具 | 能力 | 特点 |
|------|------|------|
| **LivePortrait** | 肖像/视频 → 表情 + 姿态驱动 | 开源、轻量、本地可跑，形象自然 |
| **MuseTalk** | 音频 → 嘴部精准驱动 | 开源、口型同步质量高，需显卡 |
| **HeyGem** | 音频 + 肖像 → 数字人视频 | 开源本地版，开箱即用，集成度高 |
| **Wav2Lip / SadTalker** | 老牌音频驱动口型 | 社区成熟，可作为兜底 |

### 4.2 训练/构建流程（范式，命令以官方仓库为准）

```bash
# ① 准备授权素材
#    portrait_video.mp4  (正脸讲话 1–5 分钟)
#    voice_ref.wav       (授权干净人声 10–30s)

# ② 预处理（人脸检测 / 对齐 / 切分）—— 多数工具自带
# python preprocess.py --input portrait_video.mp4 --output data/processed

# ③ 训练形象模型（或加载官方预训练权重后微调）
#    —— 具体训练命令/超参以所选工具官方 README 为准，此处为范式占位 ——
# python train.py --data data/processed --cfg configs/your_config.yaml

# ④ 导出形象模型 + 声音克隆（声音见 §8 各方法）
#    → 得到 model/avatar.pth + voice/cloned_voice

# ⑤ 推理驱动（见 §9.5 统一接口 / 下方第 7 节串联）
# python infer.py --audio out.wav --avatar model/avatar.pth --output dh.mp4
```

> ⚠️ **命令会随工具版本变化**，不要照抄上例直接跑——以所选工具的官方文档/仓库为准。
> 本地训练通常需要 **NVIDIA 显卡 + CUDA + 对应 Python 环境**（建议独立 conda/venv）。

## 5. SaaS 平台范式（免训练，秒级克隆，按量计费）

适合"不想配环境、要快、素材合规可上传"的账号。把授权素材传上去，平台自动生成形象 + 声音。

### 5.1 主流平台（国产优先，国内直连）

| 平台 | 厂商 | 特点 |
|------|------|------|
| **即创** | 字节跳动 | 抖音生态深度集成，口播数字人 |
| **硅基智能 / 硅基流动** | 硅基 | 数字人直播/口播，国内成熟 |
| **腾讯智影** | 腾讯 | 数字人播报，模板丰富 |
| **如影** | 阿里 | 电商/口播数字人 |
| **曦灵** | 百度 | 数字人平台，2D/3D |
| **闪剪 / 万兴播爆** | 第三方 | 短视频口播数字人，轻量 |
| **可灵 AI** | 快手 | 视频生成 + 数字人方向 |
| **HeyGen / D-ID** | 海外 | 国际化、多语种，需外网 |

### 5.2 流程（通用）
1. 注册并完成实名（平台合规要求）。
2. 上传**授权**肖像视频 / 肖像图 + 授权人声 → 平台生成形象 + 声音（秒级~分钟级）。
3. 在平台内输入文案 → 选择形象/声音/模板 → 生成数字人视频。
4. 导出 mp4，再按本 skill 流程补 AI 标识、过合规闸门后发布。

> 成本：SaaS 通常**按生成分钟数计费**或订阅制；本地训练是"一次性算力 + 零云费"。

---

## 6. 合规红线（必读，与 §9.5 / 大脑层合规六闸一致）

1. **授权是硬前提**：肖像 + 声音都必须取得权利人明确授权，缺授权一律不出片。
2. **深度合成标识**：依据《人工智能生成合成内容标识办法》（2025.9.1 施行），数字人视频必须同时加：
   - **显式标识**：画面内可见的"AI 生成/合成"字样（前 5 秒 ≥3 秒可见，见 `ai_label_config`）。
   - **隐式标识**：嵌入元数据（平台/SaaS 通常自动加，本地出片需自行补充）。
3. **禁止项**：未授权人脸、克隆他人/公众人物、未成年人、诈骗仿冒、不实背书——一律不做。
4. **账号层面**：在抖音创作者后台按平台要求申报 AI 生成内容，避免下架/限流。

## 7. Path A 出片串联（结合本 skill 已有能力）

训练好数字人后，出片走 Path A 的下游统一接口：

```python
# ① 用 §8 任意配音方法生成专属音色音频（已克隆声音）
dub_result = dub(text=optimized_script, method="baike",   # 或 gptsovits / cosyvoice
                 reference_audio="cloned_voice.pt", language="zh")

# ② 用 §9.5 数字人通道驱动训练好的形象
render(dub_result["audio_path"],
       channel="digital_human",
       shots=None, aspect_ratio="9:16",
       ai_label_config={"mode": "overlay", "duration_sec": 3,
                        "portrait": "trained_avatar.png",   # 训练好的形象
                        "avatar_model": "model/avatar.pth"}) # 本地训练的模型（SaaS 用平台形象 id）
```

## 8. 选型决策：本地训练 vs SaaS

| 你的情况 | 选 |
|---------|-----|
| 不想上传素材、要完全私有、有显卡 | **本地训练**（LivePortrait / MuseTalk / HeyGem） |
| 要快、不想配环境、素材可合规上传 | **SaaS 平台**（即创 / 硅基 / 智影 / 如影 等） |
| 要品牌专属 IP、长期矩阵号 | 本地训练专属形象 + SaaS 做批量变体 |
| 只想偶尔出一条口播 | SaaS 秒级克隆最省事 |

> 无论哪种，**授权 + 显式/隐式 AI 标识**都不可省略。
